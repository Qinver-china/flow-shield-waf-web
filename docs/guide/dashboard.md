# 总览面板

面板入口：**概览 → 总览**。用来一眼看：系统正不正常、最近有没有异常流量、拦了多少、哪些规则/IP 最扎眼。

![总览面板1](/images/dashboard-2.jpg)

## 页面上大概有什么

### 健康状态

看各个组件是否正常。有红灯时，先到服务器上看容器日志（见 [快速开始](./quick-start.md) 常用命令）。

### 配置数量

站点、规则、黑白名单、限速等有多少条，方便确认「策略是不是已经建好了」。

### 态势与趋势

- 请求量、拦截、放行、独立 IP、命中情况
- 近 24 小时趋势；可按站点筛选
- 流量相对平时偏高/偏低时会更显眼

### TOP 与分布

命中最多的规则、攻击 IP、拦截来源国家、各类处置占比等（以你当前面板版本为准）。

## 怎么用总览做判断

1. 健康都正常 → 再看拦截是否突然变多  
2. 拦截突增 → 点进 [防护日志](./logs.md) 看是哪条规则、哪个 IP  
3. 流量异常 → 结合 [预警](./alerts.md) 或 [AI 防护](./ai-guard.md)  
4. 改完策略回来看一眼，趋势是否符合预期  

## 常见误区

- 把「观察命中」当成「已经拦住了」——观察只记日志，不拦人
- 没选站点筛选，看到的是全局噪音
- CDN 真实 IP 配错，国家/IP TOP 会失真

## 和别的功能怎么配合

| 看到什么 | 建议去哪 |
|----------|----------|
| 健康红灯 | 部署 FAQ、容器日志 |
| 拦得太多 | 日志 → 收紧规则或加例外 |
| 几乎没日志 | 有没有流量、DNS 是否指过来、日志采样设置 |
| 机器很卡 | 可能在被刷，或限速/规则过重，见应急实践 |
