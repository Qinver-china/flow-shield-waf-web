# IP 组管理

把一批 IP / 网段收成一个组，写条件时选「属于 / 不属于该组」即可，不用到处复制粘贴。

面板入口：**观测 → IP 组管理**。

![IP 组列表](/images/ip-groups-list.png)

## 怎么建一组

1. 点 **新建**，填名称，备注可选
2. **条目**：每行一个 IP 或网段（如 `203.0.113.10` 或 `10.0.0.0/24`）
3. 支持手动添加、批量粘贴、导入 txt / csv（按面板提示）
4. 保存；列表会显示条目数

## 在条件里怎么用

写白名单、黑名单、例外、限速前置条件、自定义规则时：

1. 字段选 **客户端 IP**
2. 比较选 **属于 IP 组** 或 **不属于 IP 组**
3. 在下拉里点你建好的组

详见 [在面板里加条件](./rules-basics.md)。

## 适合放什么

- 办公网出口、机房运维 IP
- 临时封禁的攻击源集合（再配黑名单）
- 合作方回调 IP

## 注意

- 组里别塞 `0.0.0.0/0` 这种「全世界」——条件会失去意义
- 改组内容后，所有引用该组的策略会一起跟着变，改前想清楚
