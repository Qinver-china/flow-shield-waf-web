# 证书管理

面板入口：**资产 → 证书管理**。用来上传 SSL 证书，给站点开 HTTPS；也可开到期提醒。

## 怎么填

| 字段 | 白话说明 |
|------|----------|
| 名称 | 方便你辨认的名字 |
| 备注 | 可选说明 |
| 证书内容 | PEM 格式证书（可粘贴或上传文件） |
| 私钥内容 | 对应的私钥 |
| 到期前通知 | 打开后，到期前约 7 天内每天提醒一次 |
| 通知通道 | 可多选；要提醒就必须至少选一个；先在 [系统设置 → 通知通道](./settings.md) 配好邮件 |

保存后，面板会读出证书里的域名和有效期。列表可按是否快到期筛选。也可在右上角点「从其他面板导入」，抽屉里选宝塔或 1Panel，把已部署到站点的证书一次写入流盾证书库（按 PEM 指纹去重）。逐步操作见 [从其他面板导入](./panel-import.md)。

## 推荐步骤

1. 准备好完整证书链和私钥（PEM）
2. 新建证书并粘贴/上传
3. 需要提醒就打开到期通知并选择一个或多个邮件通道
4. 到 [站点配置](./sites.md) 开启 HTTPS 并选这张证书；也可在导入站点时一并带上证书

## 和别的功能怎么配合

- 站点开启 HTTPS 时绑定这里的证书
- 到期提醒依赖邮件通道已配好且能发出去

## 常见踩坑

- 只传了站点证书、没带中间证书 → 部分浏览器报证书问题
- 开了通知但没配 SMTP → 收不到提醒
- 证书过期没换 → HTTPS 站点打不开

更多排错见 [站点与证书 FAQ](./faq-sites.md)。从宝塔 / 1Panel 批量接入见 [从其他面板导入](./panel-import.md)。
