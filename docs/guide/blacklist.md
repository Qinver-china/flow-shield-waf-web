# 黑名单

命中黑名单会**马上拦截**。适合已经确认的攻击 IP、恶意特征。

面板入口：**策略 → 黑名单**。

## 怎么加一条

1. 从 [防护日志](./logs.md) 先看清攻击特征（IP、路径、UA 等）
2. 点 **新建**，填名称
3. 选 **生效站点**（不选 = 全局）
4. 写 **命中条件**（至少一条，不能为空）
5. 需要时打开 **自定义拦截页**，选状态码，写给访客看的 HTML
6. 启用并保存，再回日志确认已被拦截

::: danger 禁止空条件
产品不允许保存空条件黑名单，避免一不小心拦掉整站。
:::

## 适合拦什么

- 已确认的攻击源 IP / 网段（建议先放进 [IP 组](./ip-groups.md)）
- 明确的恶意 UA、路径特征
- 应急封禁（见 [攻击应急处置](./practice-incident.md)）

特征还拿不准时，优先用 [自定义规则](./rules.md) 先「观察」，别一上来就黑名单。

## 注意

- 条件写太宽（尤其正则）容易误伤正常用户
- 打 CC / 刷接口，优先用 [速率防护](./ratelimit.md)，不要全靠黑名单堆 IP
- 白名单里的流量不会进黑名单
