# AI 与通知 FAQ

相关教程：[AI 防护](./ai-guard.md) · [预警通知](./alerts.md) · [系统设置](./settings.md)

## AI 助手连不上 / 没反应

检查 API 地址、密钥、模型名，在 AI 配置页点「测试连接」。确认总开关和「智能聊天」已开；容器要能访问外网。仍不行看应用容器日志。

## 自动拦出一堆奇怪规则

应用模式开了「自动拦截」，或置信度太低、触发太宽。改回「仅建议」或「自动观察」，提高置信度，加长冷却；在分析记录里回滚误加规则。

## 分析一直停在「分析中」或失败

模型超时、一次拉的日志太多、或额度用尽。降低单次分析条数，换模型，看事件失败原因，检查网络和 API 余额。

## 预警开了却收不到邮件

1. 系统设置里邮件「测试发送」是否成功  
2. 策略是否勾选该通道且已启用  
3. 条件是否真的触发（阈值、窗口、站点范围）  
4. 是否还在冷却期  
5. 看垃圾箱  

## 短信 / Webhook / 钉钉没用？

当前版本以**邮件**为准，其它多为预留。请用邮件通道。

## AI 邮件里的链接打不开

在系统设置填好 **外网面板 URL**（含协议和端口），并确保收件人网络能访问。

## 证书到期通知和预警是一回事吗？

不是。证书到期在证书编辑页配；流量 / 安全 / CPU 预警在预警通知页。两边都依赖通知通道。
