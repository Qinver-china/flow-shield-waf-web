## 几条总原则

1. **先观察，再拦截**——用日志证明误伤可控  
2. **先配对真实访客 IP，再调限速**——否则 CC 策略会失真  
3. **条件尽量紧，范围尽量小**——能只绑一个站就别全局  
4. **改完能回滚**——先导出配置，或记下规则名
