# 白名单

命中白名单的访问会**跳过后面所有防护**，直接进源站。适合办公网、监控探针这类「绝对可信」的来源。

面板入口：**策略 → 白名单**。

## 怎么加一条

1. 点 **新建**
2. 填 **名称**（必填），备注可选
3. **生效站点**：选具体站点；不选 = 对所有站点生效
4. 配 **命中条件**（例如：客户端 IP 属于办公网网段，或属于某个 [IP 组](./ip-groups.md)）
5. 打开 **启用**，保存

![新建白名单](/images/whitelist-create.png)

::: warning 空条件很危险
允许保存空条件，但启用时会二次确认——空条件等于在作用范围内**全部放行**，等于关掉防护。
:::

## 适合放什么

- 公司办公网出口 IP
- 监控 / 探针 IP
- 已确认的合法爬虫（可配合 [Bot 库](./bots.md)）
- 内部健康检查来源（更精细时用 [防护例外](./exceptions.md)）

## 和「例外」差在哪

| | 白名单 | 防护例外 |
|--|--------|----------|
| 效果 | 整段跳过全部防护 | 可只跳过规则，或只跳过限速 |
| 典型用途 | 可信身份整段放行 | 支付回调、健康检查等特定路径 |

## 注意

- 条件别写太宽（过大网段）
- 启用后用该来源访问一次，到 [防护日志](./logs.md) 确认是放行、没有再被规则挡住
- 别用白名单代替精细例外——否则本该限速的流量也被放过了
