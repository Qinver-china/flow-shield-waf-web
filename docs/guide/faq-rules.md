# 防护与规则 FAQ

相关教程：[防护策略总览](./protection-basics.md) · [在面板里加条件](./rules-basics.md) · [速率防护](./ratelimit.md)

## 规则配了，日志却没命中

逐项查：

1. 规则启用了吗？生效站点包不包含当前站？  
2. 条件是不是太严，或字段取不到（如内网没有地理信息）？  
3. 是不是被白名单 / 例外提前跳过了？  
4. 日志采样是否跳过了观察？  
5. 请求有没有真正进这个站点（域名 / DNS）？  

到防护日志筛「观察」，必要时仅在测试环境开调试头核对。

## 观察模式会拦人吗？

不会，只记日志。要拦请改成拦截或人机验证。

## 为什么黑名单不能空条件？

防止误拦全站。至少写一条有效条件。白名单空条件等于全放行，启用时会二次确认。

## 限速好像没生效

查：是否启用、前置条件是否匹配、是否被「跳过限速」例外放过、优先级、真实 IP 是否正确。若动作仍是观察，超限也只记日志。

## 限速误伤很多人

常见于 CDN 没配真实 IP，所有人挤在同一边缘 IP。先改站点客户端 IP 获取方式，再调阈值；单路径被刷用「IP + 路径」。

## 限速计数异常会不会全站被拦？

默认异常时放行，建议保持。若在系统设置关掉了，异常时可能误拦。

## Bot 库加了为什么不拦？

Bot 库只负责识别。要拦截，请用规则 / 名单引用 Bot 相关字段并设动作。见 [Bot 库](./bots.md)。

## 例外「跳过范围」怎么选？

| 需求 | 选 |
|------|-----|
| 某路径完全不检测 | 跳过全部（条件必须紧） |
| 还要限速，跳过 WAF 规则 | 跳过自定义规则 |
| 还要规则，跳过 CC | 跳过限速 |

## 内置种子可以删吗？

可禁用、改动作或删除。建议先看日志再收紧；不需要的禁用即可。已有环境不会因升级自动覆盖你改过的策略。
