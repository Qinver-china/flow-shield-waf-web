# 流盾 WAF 官方网站

基于 [VitePress](https://vitepress.dev/) 的流盾 WAF（Flow Shield WAF）官方站点与文档。

## 本地开发

```bash
npm install
npm run docs:dev
```

浏览器打开终端提示的本地地址即可预览。

## 构建与预览

```bash
npm run docs:build
npm run docs:preview
```

## 目录说明

```
docs/
├── index.md              # 首页
├── .vitepress/           # VitePress 配置与主题
└── guide/                # 用户手册（简介 / 部署 / 功能 / 条件 / FAQ / 最佳实践）
```
